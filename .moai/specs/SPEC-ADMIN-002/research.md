# SPEC-ADMIN-002 Research — 레거시 admin 재분석 (Playwright 실사 기반)

## 0. 배경 및 방법

기존 spec.md(v1.0.0, 2026-06-14)는 frontmatter에 `related-research: SPEC-ADMIN-002/research.md`를 명시했지만 실제 research.md가 존재하지 않았다 — 즉 레거시 admin을 실제 화면 단위로 열어 확인하지 않고 PHP 코드의 `disp*` 디스패치 함수명 인벤토리만으로 작성되었다. 이번 작업은 Playwright로 레거시 admin(`http://localhost:8080/`, admin 세션 유지 중)을 실제로 열어, **사용자가 지정한 7개 카테고리 순서**로 화면을 재확인하고, rhymix-ts 코드(`apps/web/app/admin/`)와 직접 대조했다.

**중요 발견**: 레거시 admin의 좌측 사이드바 구조 자체가 정확히 사용자가 요청한 7개 카테고리와 일치한다 — 즉 이 순서는 임의의 분류가 아니라 **레거시 Rhymix admin의 실제 1차 네비게이션 구조**다.

```
대시보드
사이트 제작/편집
회원
콘텐츠
즐겨찾기
설정
고급
```

rhymix-ts 현재 사이드바(`apps/web/components/admin/AdminSidebar.tsx`)는 이를 `대시보드 / 콘텐츠 / 사이트 설정 / 회원 / 시스템` 5개 그룹으로 재구성해 놓았다 — 레거시 IA와 1:1 대응되지 않아 기능 누락이 시각적으로도 드러나지 않는 구조적 문제가 있다.

## 1. 대시보드

### 레거시 인벤토리 (legacy-dashboard-index.png, legacy-dashboard-with-nav.png)

- 위젯 3개: **회원**(최근 가입 admin 링크, 더보기), **최근 글**(문서 2건, 작성자/모듈명), **최근 댓글**(0건 시 "등록된 데이터가 없습니다")
- 하단 admin 유틸리티 바(전 페이지 공통 footer): 관리자 메뉴 초기화 | 캐시파일 재생성 | 세션 정리 | 코어 파일 정리 | 서버 환경 표시 | 버그 리포트(외부 링크)

### rhymix-ts 구현 상태

- REQ-ADMIN2-001~010 (대시보드 위젯, 방문자 통계, 최근 문서/댓글, graceful degradation)으로 기존 spec.md에 이미 상세히 정의되어 있음 — **내용은 정확함, 추가 발견 없음**.
- **신규 발견**: 레거시 하단 footer의 "관리자 메뉴 초기화 / 캐시파일 재생성 / 세션 정리 / 코어 파일 정리 / 서버 환경 표시 / 버그 리포트" 6개 유틸리티 링크는 기존 spec.md에 일부만 흩어져 있다 (코어파일 정리=REQ-ADMIN2-149, 서버환경=REQ-ADMIN2-144/145). "관리자 메뉴 초기화"와 "세션 정리"는 spec.md에 전혀 없음.

### 신규 REQ 후보

- **REQ-ADMIN2-CAND-A1**: admin 레이아웃 전역 footer에 "관리자 메뉴 초기화"(admin 메뉴 캐시 무효화) 액션 제공. (legacy: 관리자 메뉴 초기화)

## 2. 사이트 제작/편집

### 레거시 인벤토리 (legacy-site-edit-sitemap.png, legacy-site-edit-design.png)

- **사이트 메뉴 편집**: Main Menu / Utility Menu / Footer Menu / unlinked 4개 트리, 검색창, "사이트맵 추가" 버튼. 메뉴 트리는 접고 펼 수 있는 구조.
- **사이트 디자인 설정**: PC/모바일 탭. 4개 슬롯 — 레이아웃[XEDITION], 문서 페이지[Default Page Skin], 게시판[XEDITION], 회원[회원 기본 스킨] — 각각 미리보기 썸네일 + 선택 화살표. "PC 설정 저장" / "취소" 버튼.

### rhymix-ts 구현 상태

- 메뉴 편집(`/admin/menu`)·디자인 에디터(`/admin/site/design`, SPEC-THEME-POLISH-001) 모두 **구현됨**.
- 4개 슬롯 중 "회원 스킨" 선택은 spec.md REQ-ADMIN2-053(회원 디자인 설정, P3, "Where 지원되는 경우")으로만 약하게 다뤄짐 — 레거시에선 명확히 사이트 디자인 설정의 1차 탭이므로 우선순위 재검토 필요.
- REQ-ADMIN2-020~031 (레이아웃 관리, 페이지 편집, 메뉴 DnD)은 기존 spec.md 내용과 정확히 일치. **추가 발견 없음**.

### 신규 REQ 후보

없음 (기존 REQ-ADMIN2-020~031로 충분히 커버됨). 단, REQ-ADMIN2-053의 우선순위를 P3→P2로 재검토할 가치가 있음 (레거시에서는 "준비중"이 아니라 1차 탭으로 노출됨).

## 3. 회원

### 레거시 인벤토리 (legacy-members-list.png, legacy-members-groups.png)

- **회원 목록**: 필터 탭(모든 회원/최고 관리자/승인/거부/미인증), 간단보기·상세보기 토글, 회원 추가/수정/삭제 버튼, 컬럼(아이디/이메일/이름/닉네임/상태/가입일/최근 로그인/회원 그룹/조회·수정), 그룹별·아이디별 검색.
- **회원 그룹**: 그룹 제목(인라인 편집) + 설명 + 기본그룹 라디오 + 그룹별 삭제, "추가" 링크로 그룹 신설, 그룹 이미지 마크 사용 여부 토글.

### rhymix-ts 구현 상태

- 회원 목록(`/admin/members`)은 구현됨. 회원 그룹(`/admin/members/groups`)은 **사이드바에 `disabled: true`로 "준비중"** — REQ-ADMIN2-040~043으로 정의되어 있어 **신규 발견 없음, 기존 REQ 정확함**.
- 회원 목록의 "최고 관리자/승인/거부/미인증" 상태 필터 탭은 spec.md에 명시적 REQ 없음 (REQ-ADMIN2-040대는 그룹 관리, 044대는 등록 위주).

### 신규 REQ 후보

- **REQ-ADMIN2-CAND-C1**: 회원 목록 페이지에 상태 필터(전체/최고관리자/승인/거부/미인증)를 탭 형태로 제공. (legacy: 회원 목록 상단 필터)

## 4. 콘텐츠

### 레거시 인벤토리 (legacy-content-boards.png, -documents.png, -comments.png, -content-files.png)

- **게시판 관리**: 번호/모듈 분류/도메인·URL/브라우저 제목/특이사항/등록일/편집(설정·복사·삭제) 컬럼, 모듈 이름 검색.
- **문서**: 탭(문서 목록/기본 설정/신고 목록). 목록은 상태 필터(전체/공개/비밀/임시/신고 목록), 간단보기·상세보기, 휴지통·삭제·이동·복사 일괄 작업, 컬럼(제목/글쓴이/조회수/추천/날짜/IP주소/상태).
- **댓글 관리**: 탭(댓글 목록/신고 목록), 상태 필터(전체/공개/비밀/대기/발행), 휴지통·삭제·발행중지·발행 일괄 작업.
- **파일 관리**: 탭(첨부 파일 목록/파일 업로드 설정/파일 다운로드 설정/기타 설정), 상태 필터(전체/유효/대기), 파일 크기·이미지 크기·다운로드·작성자·날짜·IP·상태·편집 컬럼.

### rhymix-ts 구현 상태

- 게시판 관리(`/admin/modules`) 구현됨.
- 전체 문서/댓글 관리는 REQ-ADMIN2-070~077로 이미 상세 정의(필터/일괄작업/신고 포함) — **일치**. 단, 문서 상태 필터에 "임시" 상태가 spec.md에 명시되지 않음 — 임시저장 문서도 관리 대상에 포함되어야 함을 명확히 할 필요.
- 파일 관리는 REQ-ADMIN2-078~082로 이미 다뤄짐 — 탭 구조(목록/업로드설정/다운로드설정/기타설정)까지 정확히 일치. **추가 발견 없음**.

### 신규 REQ 후보

- **REQ-ADMIN2-CAND-D1**: 전체 문서 관리 목록의 상태 필터에 "임시"(완료되지 않은 자동저장본)를 포함. (REQ-ADMIN2-070 보강)

## 5. 즐겨찾기

### 확인 결과

레거시 사이드바에 "즐겨찾기" 1차 카테고리가 존재한다(스크린샷 1, 2에서 확인). 본 분석에서는 빈 상태(즐겨찾기 항목 0개)였기 때문에 화면 상세까지는 진입하지 못했으나, rhymix-ts의 `AdminFavorite` 사이드바 기능(SPEC-ADMIN-EXTRAS-001, DnD 재정렬 지원, `/admin` 전역 사이드바에 통합)이 레거시의 즐겨찾기 메뉴 위치와 정확히 대응되며 **기능적으로 이미 동등하거나 우월(DnD 지원은 레거시에 없음)**.

### 신규 REQ 후보

없음. 기존 구현으로 충분.

## 신규 발견 사항 요약

기존 spec.md(149개 REQ)는 실제로 매우 포괄적이며, 코드 대조 결과 **대부분의 "갭"은 이미 REQ로 정의되어 있고 구현만 대기 중인 상태**였다. 1차 조사(06-18) 신규 발견 8건 + 2차 실측(06-19, 설정 5탭 Playwright 재진입) 발견 4건, 총 12건:
