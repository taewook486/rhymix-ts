## 2. 여전히 남아있는 갭 (재확인)

| 공개 페이지 헤더의 로그인 상태 반영 | 즉시 반영 (상단에 닉네임+로그아웃 메뉴) | **재현됨.** `/login`에서 로그인 성공 → `/`로 리다이렉트되지만 헤더는 계속 "로그인" 표시. `/admin` 진입 시 사이드바 우측엔 "관리자 1 / 로그아웃" 정상 표시 — 공개 레이아웃 헤더 컴포넌트만 세션 미반영 | 🔴 UI 버그 — 재현 확인 (`rhymix-ts2/07-admin-dashboard-header-bug.png`: `/admin` 내부인데도 상단 배너가 "로그인" 표시) |

## 3. 홈페이지 레이아웃/콘텐츠 풍부도 — 핵심 차이 (신규 상세 비교)

REQ-016~018으로 "에러 화면"은 해소되었으나, 레거시와 비교하면 여전히 구조적으로 매우 단순하다.

| 영역 | 레거시 홈 (`legacy2/05-home-after-install.png`) | rhymix-ts 홈 (`rhymix-ts2/06-home-after-install.png`) |
|---|---|---|
| GNB 메뉴 | Welcome(홈) / Free Board / Q&A / Notice — **4개, 홈 전용 메뉴 포함** | Board / Notice / Q&A — **3개, 홈 전용 메뉴 없음**(board가 곧 홈) |
| 히어로 영역 | 자동 슬라이드 캐러셀 5장(디자인 슬로건 문구) | 없음 |
| 환영 위젯 | "HELLO, WORLD! / WELCOME TO RHYMIX" 카피 + "시작하기" CTA 버튼 | 없음 (board 게시글 목록만 노출) |
| 운영자 온보딩 패널 | "BUILD YOUR SITE" — 사이트 제목/메뉴/레이아웃/모듈/초기화면 변경 가이드 링크 6종 | 없음 |
| 커뮤니티 패널 | "GET INVOLVED" — COMMUNITY/Q&A/DOWNLOAD/GITHUB 외부 링크 4종 | 없음 |
| 본문 콘텐츠 | (Welcome 모듈은 페이지형, 별도 board에 샘플 없음 — 텍스트 위주) | board 모듈에 샘플 글 1건 목록 표시 + "글쓰기" 버튼 |
| 하단 admin 툴바 | 로그인 시 화면 최하단에 고정 바: "admin / 로그아웃 / 최근 로그인 / 관리" | 없음 (헤더의 "로그인" 링크만 존재, 로그인해도 안 바뀜 — 위 2번 버그) |
| 푸터 | Terms of Service / Privacy Policy 링크 + "Powered by Rhymix" | 없음 (홈 화면에 푸터 자체가 없음) |

**해석**: rhymix-ts의 board 인덱스 모듈은 "최소 기능 의미의 홈"(게시판 목록)이지, 레거시처럼 신규 운영자를 위한 랜딩 페이지(히어로 + 온보딩 가이드 + 커뮤니티 링크)는 아니다. REQ-016~018 범위는 "에러 없이 뜨는 것"까지였고, 랜딩 페이지 경험 자체는 SPEC 범위 밖이었던 것으로 보인다.

## 4. 우선순위별 정리

1. **[🔴 Critical, 재확인] 공개 페이지 헤더가 로그인 상태를 반영하지 못함** — `/admin` 내부에서도 상단 공개 헤더가 "로그인"으로 고정. 세션 컨텍스트가 헤더 컴포넌트까지 전파되지 않는 것으로 추정.
2. **[🟡 Major, 재확인] 설치 완료 후 자동 로그인 누락** — 레거시 대비 추가 단계 필요.
3. **[🟡 Major, 신규] `/install/complete` 안내 문구가 실제 시드 상태와 불일치** — "첫 모듈 인스턴스를 생성하세요" 문구를 REQ-016~018 구현 결과에 맞게 갱신 필요.
4. **[🟡 Major, 정보] 홈페이지가 레거시 대비 "랜딩 페이지" 요소(히어로/온보딩 패널/커뮤니티 링크/푸터)가 전혀 없음** — REQ-016~018은 충족했으나 신규 운영자 온보딩 경험 격차는 그대로. 별도 SPEC 검토 대상.
5. **[🟢 Minor, 재확인] SSL 기본값이 "항상 HTTPS 사용"** — 로컬 개발 편의상 기본값을 "HTTPS 미사용"으로 바꾸는 것을 고려.
6. **[🟢 Info, 재확인] `NEXTAUTH_SECRET` 고정 상태에서 DB만 초기화하면 유령 세션이 남음** — 테스트/스테이징 가이드에 "쿠키 전체 삭제 또는 시크릿 로테이션" 안내 필요.
