## Key Design Decisions

| Decision | Rationale |
|----------|-----------|
| **HMAC-SHA256** | Eliminates plaintext token storage risk; matches industry standard (OAuth 2.0 authorization codes). |
| **Path A Migration** | Dev environment — plaintext data deleted, columns replaced. Prod data migration deferred to Slice F. |
| **Atomic Rotation** | current → previous (single row update); new token issued from same id. Zero race condition exposure. |
| **Route Handler Scope** | Cookie rotation only. JWT session handshake deferred to Slice F (NextAuth signIn integration). |
| **No Grace Window** | previousTokenHash immediate reuse detection. No replay tolerance. |
